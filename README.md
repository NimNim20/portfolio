# Benjamin.dev

My personal developer portfolio, built to showcase my projects, technical skills, background, and journey into web development.

The portfolio is designed and developed from scratch with a focus on clean code, reusable components, responsive design, and a simple developer-inspired visual identity.

## About the Project

This portfolio serves as both a personal introduction and a showcase of my work as a web developer.

Rather than simply listing technologies and projects, the site is designed to tell the story of my development journey from my background in multimedia design to working with modern frontend and full-stack technologies.

The design combines a professional and minimal interface with subtle developer-inspired elements such as monospace typography, status indicators, structured section numbering, and technology-focused components.

## Tech Stack

The portfolio is currently built with:

- React
- TypeScript
- Vite
- SCSS

Additional technologies may be introduced as the project develops.

## Design

The visual identity is centered around a dark marine-blue colour palette with a minimal and technical aesthetic.

The goal is to create a portfolio that clearly communicates:

> I am a developer who also understands design.

Developer-inspired elements are intentionally kept subtle so that the projects and content remain the primary focus.

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project:

```bash
cd portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will start the local development environment, typically at:

```text
http://localhost:5173
```

## Development

Create a production build:

```bash
npm run build
```

Run ESLint:

```bash
npm run lint
```

Preview the production build locally:

```bash
npm run preview
```
